# 🌲 THE WILD ROBOT — IMAGE PROMPT LIBRARY
### Ready-to-paste AI image prompts (ChatGPT/DALL·E, Midjourney, or similar) for the Wild Robot Book Study app.

---

## HOW TO USE THIS FILE

Each numbered item below is a **complete, ready-to-paste prompt** — copy the whole quoted sentence into your image generator, no editing required. Every prompt already has the visual identity and style guardrails baked in, so they'll come out consistent with each other even if you generate them on different days or in different tools.

**Visual identity for this app — "forest-meets-circuitry":** mossy greens, soft driftwood browns, warm copper/bronze (echoing Roz's metal body), and pale sky blue, with a recurring motif of thin circuit-line patterns growing like vines through leaves and branches — symbolising a robot slowly becoming part of the natural world. This matches the app's existing `styles.css` colour palette, so generated images will sit naturally alongside the site's buttons, cards, and headings.

⚠️ **Copyright note — read before generating anything:** Do not ask an image generator to recreate Peter Brown's actual book cover, or to draw Roz, Brightbill, Fink, or any other named character as physically described in the book (e.g. "a tall white robot with glowing blue eyes"). Every prompt below is written to produce **original, symbolic imagery** — silhouettes, motifs, and scenery inspired by the book's themes — never a likeness of the book's own copyrighted art or characters. If a generator ever produces something that looks like a specific robot character from the book or another film, regenerate with more emphasis on "abstract/symbolic, not a specific robot design."

**Recommended image sizes:**
- Hero banner / weekly banners: 1600×600px (wide, landscape)
- Icons: 512×512px (square, transparent background where possible)
- Certificate border: 1600×1200px (landscape, letter/A4-ish ratio)
- Badges: 512×512px (square)
